# 新社会人AIクエスト(アイクエ)

> 課題や締切を、相棒のAIで片付けて、今日こそ定時に退勤しよう。

スーツ姿の新社会人になって、「課題」「レポート」「締切」などの仕事(敵)に **AI を投げつけて** 片付けていく 3D アクションゲームです。
ブラウザでそのまま遊べます(PC・スマホ・タブレット対応)。

**▶ 遊ぶ:https://saborin3.github.io/aiquest/**

## どんなゲーム?

- ステージのおくにある **「退勤」ドア** に入ればクリア。全5ステージ
- 敵(仕事)は **AI を投げる** か、**上から踏んで** 倒す。踏むとスコア2倍、着地せずに続けて踏むとコンボ
- でも AI はときどき **ハルシネーション**(かんちがいして変な方向へ飛ぶ)するし、投げすぎると **レート制限** で休けいしてしまう
- ボスは AI を3発当てるごとに「差し戻しガード」で AI をはね返してくる
- 金色の「課金」ブロックを叩くと、必殺技 **課金パワー** が使える

AI は便利だけど万能じゃない。うまく付き合いながら仕事を片付ける、という新社会人の日常をゲームにしました。

### キャラクター

| キャラ | 特徴 | スコア倍率 |
|---|---|---|
| 新人 | バランス型。AI を信じてなんでも投げる | ×1.5 |
| 先輩 | 足が速くてジャンプも得意。AI の使い方も上手 | ×1.0 |
| 上司 | 足は遅いけど、AI のウソを見抜いて一度に5つ投げる | ×1.2 |

使いやすいキャラほどスコア倍率が低くなっています。

### クリアしたあとも

- **残業モード**:敵が速くて硬く、ボスはどこまでも追いかけてくる。スコア ×1.5
- **今日のお題**:毎日かわるステージ・キャラ・しばりに挑戦
- **タイムアタック**:ステージごとの最速クリアを競う
- **オンラインランキング**:PC版・Web版共通。上位10人と自分の順位を表示
- **称号・着せ替え・社員証**:やりこみ要素。どる(ゲーム内通貨)で社内ガシャを回せる
- **セーブの引き継ぎ**:ニックネームとパスワードでログインすると、どの端末からでも続きから遊べる(ゲストでも遊べます)

## 操作方法

### PC(キーボード)

| キー | 操作 |
|---|---|
| W A S D | 移動(A・D は横歩き) |
| ← → / ↑ ↓ | 向きを変える / 視点を上下 |
| Shift | ダッシュ |
| スペース | ジャンプ(短く押すと小ジャンプ) |
| F / クリック | AI を投げる |
| E | 必殺技「課金パワー」 |
| C | 視点の切りかえ(正面から見る) |
| R | この面をやり直す |
| H / Esc | 一時停止・あそびかた |

### スマホ・タブレット

左のスティックで移動、右側をなぞって視点を回します。ジャンプ・AI 投げる・課金はボタンで。横向きがおすすめです。

## 使っている技術

| 部分 | 使ったもの |
|---|---|
| Web版 | HTML / CSS / JavaScript(1ファイル)、[Three.js](https://threejs.org/) r128、Web Audio API |
| PC版(exe) | Python、[Ursina Engine](https://www.ursinaengine.org/)(Panda3D)、PyInstaller |
| サーバー | Google Apps Script + Google スプレッドシート(ランキング・セーブ・プレイログ) |
| BGM・効果音 | プログラムで作曲・合成(チップチューン) |
| キャラの声 | [VOICEVOX](https://voicevox.hiroshiba.jp/) |

ちょっとした工夫:

- PC版とWeb版で同じサーバー・同じセーブ形式を使っていて、どちらで遊んでもデータが共通
- 通信できないときはスコアやログを端末に取っておいて、つながったときに送り直す
- サーバーは同時アクセスに備えて、ロックとキャッシュで書きこみが混ざらないようにしている
- 色は色覚の多様性に配慮した配色(Okabe-Ito)をベースにしている

```
aiquest/
├── index.html   … ゲーム本体(Web版。これ1つで動く)

├── README.md
└── LICENSE
```

## 自分の環境で動かすには

`index.html` をブラウザで開くだけで遊べます(声を出すには、ローカルサーバー経由で開いてください。例:`python -m http.server` → http://localhost:8000)。

オンラインランキングを自分で用意する場合は、Google Apps Script にサーバーのコードを貼って「ウェブアプリ」としてデプロイし、`index.html` の `ONLINE.url` をそのURLに書きかえてください。サーバーの合言葉(`SECRET`)や `TOKEN_SALT` は、自分だけの値にして公開しないでください。

## プレイデータについて

ゲームの改善と研究(卒業研究)のために、プレイの記録(ステージのクリア時間・ミスの回数・AI を投げた回数など)を集めています。ニックネーム以外の個人情報は集めていません。ニックネームには本名や学籍番号を入れないでください。
